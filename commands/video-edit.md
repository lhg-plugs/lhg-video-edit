# /lhg-video-edit:video-edit —— 一句话剪口播

用户输入在 `$ARGUMENTS` 中：`[素材路径] [--target 秒数]`。目标时长缺省 60 秒。

全程加载 `lhg-ve-transcript`（转录与清洗）与 `lhg-ve-edit`（EDL 流水线）指导，剪辑工作可分派给 `editor` agent，完成后必须走 `video-audit`。

## 流程

### 1. 确认素材
- 素材路径：用户给的视频/音频文件。检查文件存在、可读；记录原始时长（`ffprobe`）。
- 问清两件事：目标时长（缺省 60 秒）、发布平台（抖音/视频号/B站，决定画幅与字幕样式）。不知道就按"竖屏 1080×1920、60 秒、抖音"默认走，不许反复追问。

### 2. 转录（加载 lhg-ve-transcript）
- 选转录路线：私密素材 → 本地 faster-whisper；普通素材 → 云端词级转录（按量计费，**先报价格再动手**）。
- 输出逐词/逐句时间戳文本，然后做文本清洗：删口头禅（那个/这个/然后/就是说…）、标气口与长停顿、修正明显口误，输出"清洗对照表"给用户确认。
- **硬规则**：清洗对照表用户没确认，不许进 EDL。

### 3. 出 EDL（加载 lhg-ve-edit 第 2–3 节）
- 按"删什么/留什么"决策树写 EDL（JSON）：保留段、删除段（口头禅/气口/废话/跑题）、切点处 30ms 音频淡变。
- EDL 写完先给用户看一遍"剪掉/保留"清单，确认后再渲染。

### 4. 渲染
- 按 lhg-ve-edit 第 5 节的 ffmpeg 模板渲染：剪辑 → 烧字幕 → 响度归一（-14 LUFS）。
- **渲染前 hook 会自动校验 EDL 有效性**（JSON 合法、无重叠、无零时长）。被拦截就修 EDL，不要关 hook。
- 长视频（>10 分钟素材）先告诉用户预计耗时，再动手。

### 5. 字幕与封面
- 字幕样式按 lhg-ve-edit 第 6 节：描边、底部安全区、单行不超 18 字。
- 封面按第 7 节：1080×1920、标题三行内、有表现力的人脸帧优先。

### 6. 自检交付
- 跑 `/lhg-video-edit:video-audit`，blocker 清零才交付。
- 交付物：`final.mp4` + 封面图 + EDL + 清洗对照表（四件套，缺一不可）。

## 硬规则
- 没有 EDL 就直接渲染 → 不许（这是本插件与"瞎剪"的分界线）。
- 转录用云端 API 之前不报价 → 不许。
- 为通过自检改审计脚本规则 → 作弊，不许。
