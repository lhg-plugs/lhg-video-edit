# /lhg-video-edit:video-audit —— 成片自检

用户输入在 `$ARGUMENTS` 中：`[交付目录]`。目录缺省为当前项目根目录。

加载 `lhg-ve-audit` 全程指导；质检工作可分派给 `qa-reviewer` agent（它只挑毛病，不改片子）。

## 流程

### 1. 跑脚本
```bash
python3 <插件目录>/scripts/audit/video_audit.py --target <交付目录> --format text
```
交付目录里应有：字幕文件（.srt/.ass/.vtt）、`edl.json`、封面图、`meta.json`（时长/响度/音乐来源）。
记下 blocker / warning / nit 的数量与明细（含文件、行号、规则说明）。

### 2. 分级与修复
- blocker：逐条修，修一条用脚本复查一条。修不掉的（如需用户重录口播）→ 列入"需人工处理"，不许为清零改规则。
- warning：修掉或写豁免理由（+有效期）；nit：顺手修。

### 3. 人工评审
按 lhg-ve-audit 第 5 节清单执行（脚本覆盖不到的）：
- 前 3 秒：钩子是否成立、画面是否有信息量
- 字幕可读性：手机端抽查 3 处（字号/描边/遮挡）
- 音画同步：切点处听 3 处有无爆音/跳帧感
- 封面点击欲：缩小到拇指大小还能看清标题吗
- 合规：题材是否踩线（金融/医疗/极限词）

### 4. 输出报告
按 lhg-ve-audit 第 6 节模板输出自查报告，结论写清"通过 / 不通过"，建议存为 `docs/audit-YYYYMMDD.md`。

## 硬规则
- 有 blocker 就说"通过" → 不许。
- 为清零改脚本规则或阈值 → 这是作弊，不许。
- 违禁词/极限词类 blocker 靠"换词"修，不许靠"删规则"修。
